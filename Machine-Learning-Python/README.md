# Machine Learning (Python)

Personal machine learning projects, kept as written. Each folder has its own README, notebook and data.

| Project | What it covers |
|---|---|
| [`Boston-Housing-Linear-Regression/`](Boston-Housing-Linear-Regression) | Predicting house prices: simple and multiple linear regression, outlier removal (z-score and IQR), feature scaling, random forest comparison, EDA with correlation heatmap and VIF |
| [`Bank-Churn-Decision-Tree/`](Bank-Churn-Decision-Tree) | Classifying whether a bank customer leaves: one-hot encoding, decision tree (entropy) with Graphviz plots, random forest, confusion matrix and accuracy |
| [`Diabetes-Logistic-Regression/`](Diabetes-Logistic-Regression) | Predicting diabetes with logistic regression: confusion matrix, accuracy, precision, recall, ROC curve and AUC |
| [`KMeans-Customer-Segmentation/`](KMeans-Customer-Segmentation) | Customer segmentation: K-means from scratch and with scikit-learn, elbow method, and five customer segments by income and spending |

Stack: Python, pandas, NumPy, scikit-learn, seaborn, matplotlib.
